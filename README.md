# erp-software-architecture.
# Módulo de Compras — Sistema ERP

Este repositorio contiene la documentación de arquitectura de software del
**Módulo de Compras**, desarrollado como parte del taller de la asignatura
de Arquitectura de Software (Universidad de Manizales).

## 📌 Descripción del taller

El objetivo de este taller fue aplicar el proceso de documentación de
arquitectura de software mediante la plantilla **arc42**, partiendo de
historias de usuario e identificando los elementos clave de la arquitectura
(contexto, bloques de construcción, vista de ejecución, despliegue,
decisiones de diseño y riesgos) para el Módulo de Compras de un sistema ERP.
